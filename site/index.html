Télécharger le SGK-Navigator

Version {{VERSION}} du {{DATE_FR}} · un fichier HTML d’environ {{SIZE_MB}} Mo · aucun compte GitHub nécessaire

Si le lien ne fonctionne pas, télécharger le fichier par ce lien ou sous Releases.

En trois étapes

  1. 1

    Télécharger

    Choisir « Télécharger le SGK-Navigator ». Le navigateur enregistre le fichier SGK-Navigator.html, en général dans le dossier « Téléchargements ».

  2. 2

    Ouvrir

    Double-cliquer sur le fichier. Il s’ouvre dans Chrome ou Edge. Aucune installation n’est nécessaire ; l’outil fonctionne aussi sans connexion Internet.

  3. 3

    Rester dans le même navigateur

    Les versions importées, les notes et les positions sont enregistrées par le navigateur, pas dans le fichier. Ouvrir donc une nouvelle version dans le même navigateur ; les données y sont de nouveau disponibles. Par précaution, exporter auparavant un fichier de projet dans l’outil.
