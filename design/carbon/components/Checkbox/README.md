# Checkbox

Kontrollkästchen schalten eine Option der Ansicht ein oder aus.

**Der Konsument liefert:** ein `<input type="checkbox">` im `<label class="ui-check">` mit Text.

- 16 px, Rahmen 1 px `ink`, eckig. Angekreuzt: `inverse-canvas` mit weissem Haken.
- Beschriftung in `body-sm`, Abstand 8 px. Mehrere Kästchen einer Gruppe stehen in einer Zeile mit 24 px Abstand.
- Für sofort wirkende Entweder-oder-Wahl `SegmentedControl` verwenden.

## Im Tool

Ersetzt `.check`, `.check-sm`.
