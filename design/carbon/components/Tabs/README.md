# Tabs

Tabs wechseln zwischen gleichrangigen Inhalten am selben Ort: Werke, Detailbereiche eines Dossiers oder einer Position.

**Der Konsument liefert:** die Tab-Beschriftungen, optional eine Zahl oder Kennung als `<small>`, den aktiven Tab und die zugehörigen Panels.

- Höhe `size-control-lg`, Polster 20 px, Unterlinie 2 px `hairline`. Aktiv: `ink`, `body-emphasis`, Unterlinie `primary`.
- `role="tablist"`, `role="tab"`, `aria-selected`. Pfeiltasten wechseln den Tab.
- Für Ansichten der App die Top-Navigation (`UiShell`) verwenden, nicht Tabs.

## Im Tool

Ersetzt `.nd-tabs`, `.nd-tab` und die Werkauswahl.
